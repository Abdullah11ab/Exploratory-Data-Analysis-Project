# Project 2: Exploratory Data Analysis (EDA)

## Project Goal
Analyze the cleaned e-commerce dataset to understand sales patterns, trends, distributions, and outliers.

## Key Deliverables & Analysis
* **Descriptive Statistics:** Calculated Mean, Median, Total Revenue, and Total Order Counts for baseline metrics.
* **Sales Trends (Pivot Tables):** Analyzed product-wise revenue performance and evaluated marketing referral channel efficiency.
* **Outlier Detection:** Flagged high-value orders (top 10%) using conditional formatting to isolate premium buyer trends.
* **Key Insights Summary:** Documented sales drivers, return rate distributions, and high-performing marketing channels.

## Tools Used
* Microsoft Excel (Pivot Tables, Descriptive Functions, Conditional Formatting)
